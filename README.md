# MELEE — Проектирование архитектуры интернет-магазина с рекомендательной системой

Учебный системно-аналитический проект крупного интернет-магазина ювелирных украшений и аксессуаров **MELEE** (расчёты в KZT). Программная реализация сайта по условию задания не требуется — представлены архитектура, модель данных, 5 матриц предпочтений и связей, алгоритмы рекомендаций, моделирование сценариев, тестирование, прототип Figma и отчёт.

## Состав материалов
- `MELEE_Architecture_Report.docx` — полный отчёт по всем разделам проекта (1–17).
- `MELEE_Recommender_System_Project.xlsx` — электронная книга со всеми таблицами, матрицами (`10x12`, `4x12`, `4x8`, `200x12`, разреженная `200x200`), каталогом из 200 товаров, 10 пользователями и журналом событий.
- `project_data/*.csv` — выгрузки всех таблиц и матриц в формате CSV.
- `figma_prototype_spec.md` — спецификация 12 связанных экранов и мобильной адаптации в Figma.

## Порядок просмотра материалов
1. Откройте `MELEE_Architecture_Report.docx` для ознакомления с архитектурой, правилами сегментации, формулами, сценариями и результатами тестирования.
2. Откройте `MELEE_Recommender_System_Project.xlsx` (листы `01`–`12`) для проверки реестра из 200 товаров, матриц и событий.
3. Используйте `figma_prototype_spec.md` при проверке интерактивных экранов и адаптивности макета.
